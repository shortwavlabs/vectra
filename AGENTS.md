# Coding agent instructions
Read docs/PRD.md, RFC-001.md, RESEARCH.md, PRESETS.md, VALIDATION.md and ROADMAP.md before coding. Work one gate at a time on review branches. Do not merge or deploy without maintainer instruction. Do not claim tests passed unless actually executed; record commands, exact versions, metrics and failures. Keep WASM engine independent of UI; no server or telemetry; never embed raster imagery in vector export. Use only licensed fixtures and dependencies. Pin versions, preserve lockfiles, document any architecture deviation. No large binary assets or secrets in git. Avoid unnecessary CI runs. Update relevant docs and gate report with every implementation PR.
