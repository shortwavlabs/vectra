# RFC-001: local vector pipeline
Status: proposed | decision owner: maintainers

## Architecture
Static React/TypeScript app via Vite+; Rust tracing core compiled with wasm-bindgen; worker adapter; no server runtime. Tailwind/shadcn and Zustand candidates, not mandatory. Keep core independent of UI and browser APIs. Prefer a single worker initially; avoid SharedArrayBuffer/threads until profiling justifies cross-origin isolation.

```text
File -> bounded decode/orient -> canonical RGBA -> preprocess
     -> segment/trace OR vector pattern synthesis -> validate scene
     -> optimize -> preview / SVG serializer / PDF adapter
```

Canonical document: version, width/height in source pixel units, ordered groups, path commands M/L/C/Q/Z, fill/stroke (sRGB + alpha), fill rule, optional clips, transforms, palette IDs and metadata. No arbitrary SVG markup, external references, scripts, embedded images or foreignObject. Use deterministic decimal serialization and locale-independent numbers. Preview and exports consume the same validated scene; optimization must not change topology or palette silently.

## Interfaces
TraceRequest {jobId, sourceRevision, rgba, width, height, presetId, presetVersion, settings, quality, seed}; TraceResult {jobId, sourceRevision, scene, metrics, warnings}; worker messages start/progress/result/error/cancel. Transfer ArrayBuffers intentionally; do not reuse detached buffers. Keep original Blob in UI and decode as needed. Cancel via worker termination/recreation if synchronous WASM cannot cooperatively yield; stale IDs rejected. Debounce slider changes; preview at capped resolution, final export from full approved resolution. Show when final geometry differs from preview due to resolution.

Rust engine accepts dimensions and validated byte slices; checked arithmetic; typed errors; no panics on malformed input. WASM adapter owns JS boundary, worker owns allocations and lifecycle. Revoke object URLs, release buffers, bound caches. Version preset schema with migrations and reject unknown operations. Seed all stochastic effects.

## Security and privacy
Accept allowlisted raster MIME/signature and decoded dimensions; limit compressed bytes and decoded pixels; reject unsupported/animated inputs explicitly. No raw user SVG import initially. DOM preview via generated safe elements, no untrusted innerHTML. No CDN scripts, analytics, remote fonts, external image URLs or model calls. CSP default-src self; script-src self and wasm-unsafe-eval only if needed; worker-src self; connect-src self (or none if compatible); img-src self blob: data: as necessary; object-src none; base-uri none; frame-ancestors none. Test actual browser behavior. Never persist artwork without opt-in; settings only locally. Explain hosting access logs separately from artwork privacy.

## Export
SVG viewBox 0 0 width height; explicit dimensions, named groups, paths, fill rule. PDF physical size mm/in converted to points at 72 pt/in; no implicit DPI confusion. RGB only initially. Validate with independent renderers and PDF resource inspection; reject raster fallback. No PDF/X or CMYK claim. SVGO optional with constrained plugins and regression tests.

## Repo structure
src/{workspace,components,workers,export,presets}; crates/vector-engine; packages/vector-engine-wasm; tests/{fixtures,golden,browser}; docs; public/_headers. Pin toolchain and lockfiles; document clean build. WASM artifacts reproducible, not hand-edited. Prefer local checks and Pages deployment builds to unnecessary paid CI.

## Alternatives
Server processing introduces privacy and compute costs; native Tauri increases packaging burden; pure JS avoids WASM complexity but requires quality benchmarks. Selected local WASM design is conditional on P0 feasibility.
