# RFC-001: local vector pipeline
Status: proposed; P0 evidence recorded 2026-11-23 (see docs/research/p0) | decision owner: maintainers

## Architecture
Static React/TypeScript app via Vite+; Rust tracing core compiled with wasm-bindgen; worker adapter; no server runtime. Tailwind/shadcn and Zustand candidates, not mandatory. Keep core independent of UI and browser APIs. Prefer a single worker initially; avoid SharedArrayBuffer/threads until profiling justifies cross-origin isolation.

```text
File -> bounded decode/orient -> canonical RGBA -> preprocess
     -> segment/trace OR vector pattern synthesis -> validate scene
     -> optimize -> preview / SVG serializer / PDF adapter
```

Canonical document: version, width/height in source pixel units, ordered groups, path commands M/L/C/Q/Z, fill/stroke (sRGB + alpha), fill rule, optional clips, transforms, palette IDs and metadata. No arbitrary SVG markup, external references, scripts, embedded images or foreignObject. Use deterministic decimal serialization and locale-independent numbers. Preview and exports consume the same validated scene; optimization must not change topology or palette silently.

## Interfaces
TraceRequest {jobId, sourceRevision, rgba, width, height, presetId, presetVersion, settings, quality, seed}; TraceResult {jobId, sourceRevision, scene, metrics, warnings}; worker messages start/progress/result/error/cancel. Transfer ArrayBuffers intentionally; do not reuse detached buffers. Keep original Blob in UI and decode as needed. Cancel via worker termination/recreation if synchronous WASM cannot cooperatively yield; stale IDs rejected. Debounce slider changes; preview at capped resolution, final export from full approved resolution. Show when final geometry differs from preview due to resolution.

Rust engine accepts dimensions and validated byte slices; checked arithmetic; typed errors; no panics on malformed input. WASM adapter owns JS boundary, worker owns allocations and lifecycle. Revoke object URLs, release buffers, bound caches. Version preset schema with migrations and reject unknown operations. Seed all stochastic effects.

## Security and privacy
Accept allowlisted raster MIME/signature and decoded dimensions; limit compressed bytes and decoded pixels; reject unsupported/animated inputs explicitly. No raw user SVG import initially. DOM preview via generated safe elements, no untrusted innerHTML. No CDN scripts, analytics, remote fonts, external image URLs or model calls. CSP default-src self; script-src self and wasm-unsafe-eval only if needed; worker-src self; connect-src self (or none if compatible); img-src self blob: data: as necessary; object-src none; base-uri none; frame-ancestors none. Test actual browser behavior. Never persist artwork without opt-in; settings only locally. Explain hosting access logs separately from artwork privacy.

## Export
SVG viewBox 0 0 width height; explicit dimensions, named groups, paths, fill rule. PDF physical size mm/in converted to points at 72 pt/in; no implicit DPI confusion. RGB only initially. Validate with independent renderers and PDF resource inspection; reject raster fallback. No PDF/X or CMYK claim. SVGO optional with constrained plugins and regression tests.

## Repo structure
src/{workspace,components,workers,export,presets}; crates/vector-engine; packages/vector-engine-wasm; tests/{fixtures,golden,browser}; docs; public/_headers. Pin toolchain and lockfiles; document clean build. WASM artifacts reproducible, not hand-edited. Prefer local checks and Pages deployment builds to unnecessary paid CI.

## Decision status after P0-R (2026-11-24)
**Accepted by the maintainer** (P0-R brief, §3):
- Stack: Vite+, React, TypeScript, Rust, WebAssembly, wasm-bindgen, module Web Workers, local-first processing. Existing pins and lockfiles are kept.
- `vtracer =1.0.0-alpha.4`, provisionally. It stays pinned exactly behind `trace.rs`, with fallback to visioncortex directly.
  - **Reconsider when:** VTracer 1.0 stable is released, or a newer alpha changes the stage API; a defect affects supported modes; upstream maintenance stops (no release or commit for more than six months); a licence change occurs; or the adapter surface grows beyond the frontends, colour fitters and compositing stages we use.
- Direct PDF writer (`pdf-writer`). jsPDF and svg2pdf.js never enter the production runtime. SVG and PDF come from one validated scene.
- Canonical scene with absolute M/L/C/Z **for the evaluated scene only**. The editable document model is RFC-002's decision (see docs/research/p0-r/P1-ARCHITECTURAL-INPUTS.md).
- Vectra-owned alpha, luminance, threshold and palette processing.
- Terminate-and-recreate cancellation. The offline recovery defect is resolved in P0-R by a versioned service worker (docs/research/p0-r/OFFLINE-WORKER-RECOVERY.md).

**Accepted later by the maintainer** (P0-R-GEO brief, §2):
- Service-worker precaching as the offline mechanism.
- Workers Static Assets (assets-only) as the hosting target. Deployment is deferred until a suitable UI exists. Tentative domains are `vectrapress.ink` and `vectrapress.com`.
- MIT license, `Copyright (c) 2026 Stephane Pericat`.
- Photographic tracing quality and speed; SVG editability; PDF dimensions and sharpness.

**Outstanding proposals** (not accepted until the maintainer says so):
- Geometry quality dispositions. Simple circular geometry was **rejected** (DEF-GEO-001, DEF-GEO-002). P0-R-GEO proposes an explicit `fit.mode = "precision"` (`PRECISION_FIT_VERSION` 1, docs/research/p0-r-geo/SELECTED-CORRECTION.md):
  - Vectra-owned sub-pixel boundary fitting replaces only VTracer's per-region curve fitting, with stacked compositing.
  - VTracer keeps segmentation.
  - The default `spline` mode is unchanged and byte-identical.
  - The remaining deviations are listed in GEOMETRY-VALIDATION.md.
- Canonical Linux container builds for published hashes.
- Revised performance budgets (docs/research/p0-r/PERFORMANCE-BASELINE.md).

## P0 evidence and deviations (2026-11-23)
These are recorded for maintainer review. None is merged into `main` until review.
- **Tracer.** `vtracer =1.0.0-alpha.4` (pluggable stages, `VectorDoc` IR, wasm-safe dependencies) with `visioncortex =0.9.3`, behind `crates/vector-engine/src/trace.rs`. The baseline's "stable release" candidate (0.6.5) was rejected after measurement: its binary threshold uses the red channel only, it keys alpha by sampled rows, and its key search used an unseeded RNG. Vectra owns luminance, threshold, invert, alpha and palette policy. See P0-G1.
- **Canonical scene.** Absolute `M/L/C/Z` only. There are no `Q` commands or transforms; quadratics become cubics and transforms are baked into coordinates. Clipping is a rectangle per group. Fill rules are explicit. Version 1 is validated on every export.
- **Exports.** SVG and PDF are both written in Rust from the validated scene. The PDF writer is `pdf-writer` 0.15.0 directly, not jsPDF + svg2pdf.js. svg2pdf.js needs the main-thread DOM, emits non-deterministic metadata, and adds unused font references. See P0-G3.
- **Cancellation.** Implemented as terminate-and-recreate: synchronous WASM cannot observe a cancel message. Workers are recycled when WASM memory exceeds 1 GiB. A worker is warmed up at start so the app works offline after load. See P0-G2.
- **CSP.** `'wasm-unsafe-eval'` is required in Chrome, Firefox and WebKit (negative control in P0-G4). `connect-src 'self'` also blocks `fetch(blob:)`, which the app does not need.
- **Decoding.** Browser decoding (`createImageBitmap` + canvas) differs across engines for JPEG and for semi-transparent pixels, so the engine is deterministic per RGBA input but not across browsers. In-WASM decoding is a P1 option. See P0-G1.
- **Asset base.** Vite `base: "./"` (relative). Switch to `/` if client-side routes are added.

## Alternatives
Server processing introduces privacy and compute costs; native Tauri increases packaging burden; pure JS avoids WASM complexity but requires quality benchmarks. Selected local WASM design is conditional on P0 feasibility.
