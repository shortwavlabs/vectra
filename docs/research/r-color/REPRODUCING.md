# Reproducing the R-COLOR measurements

Every prototype is disposable and isolated:

- `experiments/r-color/cmm` is a standalone Cargo workspace (its own `[workspace]` and `Cargo.lock`). The root workspace already excludes `experiments/*`.
- The scripts write only to `experiments/r-color/out/` (git-ignored) and, for the final copy, to `docs/research/r-color/artifacts/`.

No production file, root lockfile or production dependency is touched.

**ICC profiles.** The macOS system profiles are used **in place** (`/System/Library/ColorSync/Profiles`): sRGB Profile, Generic CMYK Profile, Display P3, AdobeRGB1998. They are never copied into the repository; their SHA-256 values are in `artifacts/cmm/profiles.sha256`. The decode probe's P3 and Adobe RGB profiles are generated by moxcms at run time.

## One command

From the repository root:

```bash
sh experiments/r-color/run-all.sh
```

This runs, in order:

1. the prototype self-checks (`cargo test`: CIEDE2000 vs Sharma 2005 pairs; ICC bounds checker);
2. the three-engine comparison;
3. the scalar and tetrahedral builds;
4. the WASM build and the bit comparison;
5. the PDF variants, structural checks and renders;
6. the raster probe;
7. the browser decode probe (all four browser configurations);
8. the malformed-profile probe.

It then copies the numeric artifacts into `docs/research/r-color/artifacts/` and formats them with a scoped `vp fmt`. It takes about 2–3 minutes once crates are cached.

Then print the figures quoted in the reports:

```bash
node docs/research/r-color/artifacts/summarize.mjs
```

## Individual steps

**Engines** (moxcms vs Little CMS vs ColorSync):

```bash
sh experiments/r-color/run-cmm.sh experiments/r-color/out/cmm
```

**WASM build and native/WASM comparison:**

```bash
cargo build --release --manifest-path experiments/r-color/cmm/Cargo.toml --target wasm32-unknown-unknown --no-default-features --lib
```

```bash
node experiments/r-color/wasm-check.mjs experiments/r-color/out/cmm/moxcms-native.json
```

**PDF variants, qpdf/poppler checks, poppler and Quartz renders, raster probe:**

```bash
sh experiments/r-color/run-pdf.sh experiments/r-color/out/pdf
```

**Browser decode probe** (needs `decode_inputs` output and the two JPEGs that `run-all.sh` creates with `sips`):

```bash
node experiments/r-color/browser-decode/probe.mjs experiments/r-color/out/decode
```

**Malformed-profile probe:**

```bash
RC_CMYK="/System/Library/ColorSync/Profiles/Generic CMYK Profile.icc" experiments/r-color/cmm/target/release/icc_fuzz experiments/r-color/out/icc-fuzz.json 2000
```

## Repository checks used for this branch

**Scoped format and lint** (never run with `--fix` at the root):

```bash
pnpm exec vp check docs/research/r-color
```

`vp check` loads `vite.config.ts`, which needs `packages/vector-engine-wasm/pkg`. Build it first with `node scripts/build-wasm.mjs` (git-ignored output).

**Production paths unchanged** (expects no output):

```bash
git diff --name-only 7f57dd716bdbec0a6160da3585b445852f464859..HEAD -- . ':!docs/research/r-color' ':!experiments/r-color'
```

## What is not reproducible here

- **Non-macOS hosts.** The ColorSync and Quartz steps need macOS. On other hosts, `run-cmm.sh` and `run-pdf.sh` must skip the `sips` steps. They currently fail; no portability work was done.
- **Renders and generated binaries.** Rendered PNGs, PDFs and TIFFs are regenerated, not committed: they embed or depend on third-party profiles.
- **Results that depend on the Playwright build.** Real Safari, and Firefox on Windows or Linux, were not run.
