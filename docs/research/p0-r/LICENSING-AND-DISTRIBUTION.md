## Third-party notices (`public/THIRD-PARTY-NOTICES.txt` → `dist/THIRD-PARTY-NOTICES.txt`)
Generated by `node scripts/generate-notices.mjs` (`pnpm run notices`); verified by `--check` inside `pnpm run build`.

**What it covers (35 components).** These are the distributed runtime dependencies:
- **Rust crates compiled into the WebAssembly module.** Normal dependencies of `vector-engine-wasm` for `wasm32-unknown-unknown`, excluding proc-macro (compile-time) crates. Derived from `cargo metadata`, which follows `Cargo.lock`.
- **npm packages bundled into the JavaScript:** react 19.3.1, react-dom 19.3.1, scheduler 0.28.0. These come from the source maps of a throwaway build, so the list is exactly what the bundler included.
- **Bundler-injected runtime code.** Vite's module-preload polyfill (MIT); its text is the "vite" section of the Vite+ core `LICENSE`.

**How texts are obtained.**
- Every `LICENSE*`, `COPYING*`, `NOTICE*`, `COPYRIGHT*` and `UNLICENSE*` file in each package is copied **verbatim** and grouped by identical text (34 distinct texts, about 225 KB).
- Dual-licensed crates have all their provided files included.
- Two crates are published without any license file, so their texts come from the projects' own repositories with recorded provenance (`scripts/notices-supplements/SOURCES.json`):
  - `vtracer 1.0.0-alpha.4`: root `LICENSE` at the release tag (commit `2500df7`).
  - `flo_curves 0.3.1` (Apache-2.0 in crate metadata): neither the crate nor the repository at the 0.3.1 tag has a license file. The author added `LICENSE` on 2021-01-10 (commit `2c814ee`, "didn't add the LICENSE file when this was split from FlowBetween") and it is reproduced verbatim.
- No notice is reconstructed.

**Obligations met.**
- MIT and BSD-2-Clause copyright notices (`roots`, BSD-2-Clause) are reproduced.
- Apache-2.0 license texts are included (`flo_curves` 0.3.1 and 0.8.1 are Apache-2.0 only). None of the distributed Apache-2.0 packages ships a `NOTICE` file; the generator would include one if present.
- Other permissive licenses are reproduced: 0BSD, Zlib, BSL-1.0, Unlicense and Unicode-3.0.

**Distribution.** The file is linked from the workbench header ("Third-party licenses"), precached by the service worker, and required by `check-dist`.
