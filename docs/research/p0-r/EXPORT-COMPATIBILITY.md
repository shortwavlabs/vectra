# P0-R-G3: Export compatibility closure

**Gate status: PASS** for the automated export regression suite after all P0-R changes. **Application compatibility (Inkscape, macOS Preview): OWNER TEST PENDING.** Inkscape is not installed on the engineering machine, so no GUI test was performed. An owner acceptance bundle and checklist are provided.

## What changed since P0
The Rust engine and its export code are unchanged since P0 commit `25e7867` (the translucent-background alpha-leak fix). P0-R changed only the application shell (service worker, instrumentation), the build and the tests. The WASM binary built on macOS at the P0-R head has the same SHA-256 as the P0 head: see "Regression results".
