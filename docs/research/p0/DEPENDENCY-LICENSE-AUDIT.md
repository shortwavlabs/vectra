- `cargo tree … --target wasm32-unknown-unknown -e normal`, joined with `cargo metadata` license fields;

**Not legal advice.** Final license selection and notice obligations remain with the maintainer.

## Project license
- README and CONTRIBUTING say "proposed MIT". There is **no LICENSE file**, and P0 does not add one; that decision is the maintainer's.
- Rust crate manifests declare `license = "MIT"` (workspace package) so that tooling can report it. Change this if the final license differs.
- All shipped dependencies below are compatible with distributing an MIT-licensed application, **provided their notices are reproduced**.

## Fixtures
- Procedural fixtures are generated by repository code, under the repository license.
- `hokusai-great-wave-640.jpg`: public domain (Wikimedia Commons `Public domain`; Met API `isPublicDomain: true`, object 45434).
- `talbot-scene-in-a-library-640.jpg`: CC0 1.0 (Wikimedia Commons; donated by The Met under its Open Access policy).
- Embedded metadata checked: JFIF, a 76-byte EXIF block (dimensions only) and the upstream IPTC catalogue reference (`JP1847`). No host, user or location data. The two workbench screenshots likewise contain only JFIF and minimal EXIF.
- No attribution is required for either. Courtesy credit lines are kept in `tests/fixtures/external/SOURCES.json`.
- The Met's own image CDN blocked automated download with bot protection. It was **not** bypassed; Wikimedia Commons copies of the same museum files were used.
