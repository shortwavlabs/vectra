# Contributing
Vectra is an open-source project in research phase. Discuss significant design changes in an issue or RFC before implementation. Use focused branches and PRs; include rationale, tests, evidence and license provenance. Do not upload confidential artwork. Preset contributions must include deterministic fixture tests and vector-only export checks. Respect the privacy and resource constraints in the RFC. Code of conduct: treat contributors respectfully; harassment is not acceptable. Vectra is MIT-licensed; the maintainer selected MIT, and the LICENSE file lands once the copyright holder line is confirmed. Contributions are accepted under the same license. If you add or upgrade a distributed dependency, run `pnpm run notices` and commit the regenerated `public/THIRD-PARTY-NOTICES.txt`; the build fails if it is stale. Never add GPL-licensed code to the distributed application.
